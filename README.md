# Knowa Island Adventures

Estamos criando um produto digital real chamado:

MISSÃO MUNDO KNN

MEU MUNDO SEM FRONTEIRAS

Público: crianças de 5 a 8 anos.

Não quero uma landing page infantil.

Quero uma experiência digital de AVENTURA / MISSÃO, como um pequeno adventure game mobile.

O universo narrativo é Knowa Island.

Jacob Knowa é o explorador que guia a criança.

Os personagens existentes são:

Tuga, Tila, Kinn e Rhino.

IMPORTANTE:

Não fique preso aos assets existentes.

Use-os quando fizer sentido, mas tenha liberdade para criar NOVOS elementos visuais, mapas, cenários, objetos, símbolos, interfaces e ambientes.

Quero que Knowa Island pareça um MUNDO, e não apenas uma imagem colocada no fundo.

A direção visual deve misturar:

ADVENTURE GAME

+ STORYBOOK

+ EXPLORAÇÃO

+ MAPA DE AVENTURA

+ PRODUTO INFANTIL PREMIUM

Evite completamente:

- aparência de landing page

- visual de SaaS

- excesso de cards

- azul marinho + bege como identidade principal

- gradientes genéricos

- visual “feito por IA”

- personagens PNG simplesmente jogados na tela

- texto sobre imagens sem contraste

- excesso de emojis

- visual infantilizado demais

Quero uma identidade visual própria, sofisticada, divertida e memorável.

Pense:

“Como seria entrar em um jogo de aventura da Knowa Island?”

e não:

“Como seria um site para crianças?”

Crie uma linguagem visual baseada em:

- mapas

- exploração

- descobertas

- territórios desconhecidos

- trilhas

- marcadores

- bússolas

- selos

- objetos de explorador

- pequenas animações

- ambientes próprios

- elementos cartográficos

Você pode construir mapas e cenários em SVG/CSS/HTML em vez de depender das imagens existentes.

Jacob também não deve aparecer sempre da mesma maneira.

Use composição, enquadramento, escala e cenário para fazer com que ele pareça realmente participar da aventura.

A experiência será principalmente MOBILE FIRST.

Priorize:

- telas de 360–390px

- botões grandes

- excelente contraste

- tipografia legível

- zero sobreposição

- animações suaves

- uma ação principal por tela

Por enquanto, NÃO implemente backend, Google Sheets ou WhatsApp.

Quero primeiro que você resolva a DIREÇÃO VISUAL e a EXPERIÊNCIA.

Crie um protótipo navegável do fluxo principal 5–8.

O objetivo é que, ao abrir a primeira tela, a criança pense:

“EU ENTREI EM UMA MISSÃO.”

Não:

“EU ABRI UM SITE.”
